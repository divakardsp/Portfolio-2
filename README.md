# Divakar Purva

A portfolio that opens like a quiet reveal and ends like a strong argument.

Live site: [https://www.divakarpurva.com/](https://www.divakarpurva.com/)

## Signal

This is a personal portfolio built to feel deliberate, minimal, and slightly kinetic. It is less about listing tools and more about shaping a voice: the kind that prefers product thinking, clean execution, and work that stays sharp under pressure.

## What it says without saying too much

- A brief animated entrance before the main layout settles in.
- A left side built for identity, contact, and first impression.
- A right side that carries projects, experience, and proof.
- A design language that leans restrained rather than loud.

## Projects

The portfolio features work across systems that move in different ways:

- AI-assisted developer workflows
- OAuth2 and OpenID Connect infrastructure
- Real-time mapping and event streaming
- Collaborative state sync with sockets and Redis

## Built with

Next.js, React, TypeScript, Tailwind CSS, Motion, Lenis, and a few pieces of polished stubbornness.
